### Exploratory AI Text Analysis Pipeline

This repository contains an exploratory pipeline developed as a part of my MA Thesis, which is publicly available [here](https://theses.cz/id/7t2uxn/).

Its aim is to statistically visualise the differences between human-written and AI generated texts using quantitative linguistic markers.
It also includes an experimental training segment for AI classifiers, using logistic regression and Naive Bayes classifiers.

#### Corpus

The original corpus used for the analysis and provided in the "English" directory was taken from [the REFCOR repository](https://github.com/cophi-wue/refcor.git).
